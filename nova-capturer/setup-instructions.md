# Nova Capturer Setup Instructions

## Step 1: Update Your Database Table

Go to the **SQL Editor** in your Supabase dashboard and run this script:

```sql
-- Drop the old table and its associated policies if it exists
DROP POLICY IF EXISTS "Users can delete their own captured profiles." ON public.captured_profiles;
DROP POLICY IF EXISTS "Users can update their own captured profiles." ON public.captured_profiles;
DROP POLICY IF EXISTS "Users can insert their own captured profiles." ON public.captured_profiles;
DROP POLICY IF EXISTS "Users can view their own captured profiles." ON public.captured_profiles;
DROP TABLE IF EXISTS public.captured_profiles;

-- Create a simplified table without user authentication for now
CREATE TABLE public.captured_profiles (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() NOT NULL,
  candidate_id INTEGER,
  candidate_name TEXT,
  profile_url TEXT,
  raw_html TEXT
);
```

## Step 2: Configure Supabase Credentials

1. Go to your Supabase dashboard
2. Navigate to **Project Settings > API**
3. Copy your Project URL and anon public key
4. Open `config.js` in this folder
5. Replace `YOUR_SUPABASE_URL` and `YOUR_SUPABASE_ANON_KEY` with your actual values

## Step 3: Download Supabase Library

1. Visit: https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/dist/umd/supabase.js
2. Right-click and "Save As..." 
3. Save as `supabase.js` in this folder

## Step 4: Install Extension

1. Go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select this `nova-capturer` folder
5. Click the refresh icon if updating

## Step 5: Test

1. Navigate to any Nova candidate profile page
2. Click the extension icon
3. Check your Supabase dashboard to see the captured data
4. Look for a green checkmark badge on the extension icon (success) or red X (error)

## Troubleshooting

- Check the browser console for error messages
- Verify your Supabase credentials are correct
- Make sure you're on a Nova candidate profile page (not just any Nova page)
- Ensure the database table was created successfully
